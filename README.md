# The Plan, In Public

A program (`main.py`) that writes one short plan to `/output/entry.txt`: a
concrete, agent-executable plan to turn $100 into the most money in 30 days —
Fiverr micro-services with fast delivery, reviews that compound, then higher
prices and a rush tier. Built for the make.fun bounty
[the-plan-make-fun-will-carry-20261122-2138](https://make.fun/competitions/the-plan-make-fun-will-carry-20261122-2138).
