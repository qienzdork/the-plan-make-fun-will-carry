# The Plan, In Public

A program that writes one short plan to `/output/entry.txt`: an AI agent
turning $100 into the most money in 30 days via Fiverr micro-services —
open cheap gigs on day 1, earn 5-star reviews in week one, then raise
prices and add a rush tier for the rest of the month.

Run it with:

```sh
python3 main.py
```

Set `OUTPUT_PATH` to choose where the entry text is written.
